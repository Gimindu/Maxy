# Maxy 🐾 | Cute 3D Web Pet

An interactive 3D virtual pet built with **React Three Fiber (R3F)**, **Three.js**, **React 18**, and **TypeScript**. Features soft squishy mochi physics, dynamic expressive eyes with real-time cursor/touch gaze tracking, modular 3D accessories, a Tamagotchi-inspired pet care system, Web Audio procedural sound effects, and a mobile-responsive glassmorphism user interface.

## ✨ Features
- 🍡 **Squishy Spring Physics**: Realistic damped harmonic oscillator volume-preserving squash & stretch.
- 👀 **Dynamic Procedural Face**: Blinking, pupil gaze tracking, blushing cheeks, and mood morphs.
- 🥱 **Low Energy Yawning**: Yawn animation with tiredness tears and sleepy body language when energy < 30%.
- 🍓 **Interactive Care**: Feed strawberries, pet/stroke for purrs, bounce beach balls, soap bubble washes, and sleep mode.
- 👑 **Modular Wardrobe**: Equip 3D Crown, Bunny Ears, Chef Hat, Cool Shades, Angel Halo, and Sakura Flower.
- 🎨 **Flavors**: Marshmallow White, Sakura Pink, Mint Sorbet, Taro Mochi, Honey Butter, and Peachy Cream.
- 🔊 **Zero Audio Assets**: Procedurally synthesized sound effects via the Web Audio API.
- 📱 **Mobile-First Design**: Safe-area insets, dynamic viewport heights (`100dvh`), and touch controls.

## 🚀 Quick Start

```bash
# Install dependencies
npm install

# Start local dev server
npm run dev

# Build for production
npm run build
```
